PCI Survey v1.1.0 - ASTM D6433-24 field app (installable web app / PWA)
1. Host this folder over HTTPS (e.g. GitHub Pages). 2. Open on each device and install.
3. Curves > Import library: load D6433-24_curve_library.json from EDI's Google Drive
   (licensed-derived data: never commit it to the public repository).
4. Settings > Load demo project reproduces the ASTM worked examples.
To release an update: replace files and change VERSION in sw.js.
